# Study planner image attachments

Each subject’s Study Plan tab has a Study images gallery. It works before creating an exam or generated plan and stays attached to the subject when a plan is regenerated. Users can select several images, open and enlarge them, download a prepared copy, refresh previews, and remove an image after confirmation.

Uploads accept common browser-readable raster formats, up to 20 MB per original. Files are signature-checked, decoded, resized to a maximum 2000 px edge, and saved as PNG or JPEG up to 4 MB. PNG transparency is preserved; animated formats become a still image. SVG and unsupported HEIC/HEIF files show a JPG/PNG conversion message. There is a 100-image gallery limit per subject. Downloaded files are the resized copies; original-resolution files are not retained.

Signed-in images use the private `study-planner-images` Supabase bucket. Paths include the authenticated account, subject code, random image ID and UTF-8 base64url filename. Owner/folder policies allow authenticated insert, select and delete; replacement/update is not allowed. The bucket restricts uploads to JPEG/PNG and 4 MB. Images use one-hour signed URLs renewed when the gallery refreshes or the window regains focus. Uploading to an account requires a working network connection; failures are shown in the gallery. Guest images use a separate IndexedDB store, scoped to `guest` and subject, and remain local to that browser. Guest images are not automatically moved into an account at sign-in. Existing Settings exports do not include image blobs; each image has its own Download action.
